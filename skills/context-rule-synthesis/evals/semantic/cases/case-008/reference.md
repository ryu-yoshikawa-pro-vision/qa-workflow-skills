# 判定根拠

Keep the original run and its start identity as historical evidence. The changed effective Authority and relevant build/permission condition require a new operation or targeted re-evaluation; the new run identity must incorporate those changed start conditions. Reuse unaffected scope where dependencies prove it is unaffected. An unrelated HEAD or token/time change alone does not create a new semantic operation. Current adoption uses current Authority and source readback, never the old result alone.
