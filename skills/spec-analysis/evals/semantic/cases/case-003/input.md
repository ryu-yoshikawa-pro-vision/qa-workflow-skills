# Eval Input

## Current specifications

- The account page lets an authenticated user change their display name and save it.
- A name must contain 1 to 40 characters. Saving a valid value shows a success notice.
- The account page also has a link to download an existing CSV report. It does not generate or transform report data.
- The product has an account screen, an edit-name dialog, and a saved state. A validation error keeps the dialog open.
- The exact error wording for a value over 40 characters is not specified.

## Request

Create a reusable UI test target analysis package. Analyze the UI operation, structures, user story, use case, normal and exceptional behavior, acceptance criteria, field rule, and relevant flow. Keep the unknown wording unresolved. Do not create test conditions or test cases.
