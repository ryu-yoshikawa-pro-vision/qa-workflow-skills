# E2Eテスト実装 出力テンプレート

## 実装対象

実装対象は最低1件必要です。入力元は、詳細TC、ユーザー明示E2E対象、既存E2E実装参照のいずれかです。TCありの新規実装では`TC ID（存在時のみ）`があれば`明示対象 / 既存E2E参照`は空欄でも構いません。TCなしでは明示対象または既存E2E実装参照を空欄にしません。実装・再利用・拡張が成立した対象の確認済み期待挙動は`未確認`、`確認不能`、`不明`等で閉じず、確定できない範囲は実装前blockにします。実装前blockでは確認済み期待挙動を`未確認`等の明示状態で記録できます。

| E2E対象 / 識別子 | TC ID（存在時のみ） | 明示対象 / 既存E2E参照 | 確認済み期待挙動 | 扱い |
| --- | --- | --- | --- | --- |
|  |  |  |  | 新規実装 / 既存E2E再利用 / 既存E2E拡張 / ブロック中 |

## E2E実装参照

実装・再利用・拡張が成立した場合は実装参照を最低1件必要とします。全対象が実装前blockの場合はE2E実装参照を0件とし、コードを作成していないため変更・再利用ファイルと実装成果物に対するPASS検証も記録しません。block理由・不足範囲・次の担当を`inspection差分・ブロック・要再検証`へ記録します。成立対象とblock対象が混在する場合は、成立対象について実装参照を保持します。実装参照はrepo-relative test fileとPlaywright title pathを用い、TCなし経路でもTC IDを創作せずに追跡可能にします。

| E2E実装参照 | test file | Playwright title path | TC ID（存在時のみ） | 扱い |
| --- | --- | --- | --- | --- |
| tests/example.spec.ts > example | tests/example.spec.ts | example |  | 新規実装 / 再利用 / 拡張 |
