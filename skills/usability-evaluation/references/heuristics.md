# Usability Heuristics

## Advisory review prompts

- [Heuristic 1: Visibility of System Status](heuristics/heuristic-01.md#visibility-of-system-status): review timely, task-relevant communication of state and outcomes.
- [Heuristic 2: Match Between System and the Real World](heuristics/heuristic-02.md#match-between-system-and-the-real-world): review language, ordering, and conventions against the user's task context.
- [Heuristic 3: User Control and Freedom](heuristics/user-control-and-freedom.md#user-control-and-freedom): review whether a relevant interaction offers a discoverable exit, cancellation, or recovery path.
- [Heuristic 4: Consistency and Standards](heuristics/heuristic-04.md#consistency-and-standards): review consistency while keeping general convention separate from project authority.
- [Heuristic 5: Error Prevention](heuristics/heuristic-05.md#error-prevention): review preventable error conditions without inventing a universal error rate.
- [Heuristic 6: Recognition Rather Than Recall](heuristics/heuristic-06.md#recognition-rather-than-recall): review visible context and memory demands for the supplied task.
- [Heuristic 7: Flexibility and Efficiency of Use](heuristics/heuristic-07.md#flexibility-and-efficiency-of-use): review relevant shortcuts and paths for the supplied user and task.
- [Heuristic 8: Aesthetic and Minimalist Design](heuristics/heuristic-08.md#aesthetic-and-minimalist-design): review competing content in context without treating density as inherently bad.
- [Heuristic 9: Help Users Recognize, Diagnose, and Recover from Errors](heuristics/heuristic-09.md#help-users-recognize-diagnose-and-recover-from-errors): review error identification and recovery support.
- [Heuristic 10: Help and Documentation](heuristics/heuristic-10.md#help-and-documentation): review task-specific help discoverability and context.

These are advisory prompts, not WCAG success criteria, project requirements, or evidence that users were confused. Evaluate applicability from the supplied task and evidence.
