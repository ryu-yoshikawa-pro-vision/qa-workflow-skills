### Heuristic 3: user control and freedom
When an interaction leaves users in an unwanted state, look for a clearly discoverable way to exit, cancel, or undo when the task allows it. The heuristic can prompt a review of dialog dismissal and recovery. It is advisory, not a WCAG success criterion or project requirement; applicability depends on the task, consequences, and available alternatives.

### Evaluation use
Record the user goal and observed controls. Do not assume that users were confused, assert a usability failure from the heuristic alone, or convert its advice into a strict requirement. Pair it with task context and direct evidence.
