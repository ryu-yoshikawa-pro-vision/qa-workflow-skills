# Platform and Design System References

No project-adopted platform or Design System is identified for this generic Web corpus. USWDS Modal is retained as an advisory source in the Dialog reference; it is not a project requirement unless the project explicitly adopts USWDS.

When the evaluated product has a declared platform or adopted Design System, follow its applicable source only after confirming that adoption and target scope. Do not apply native-platform guidance to a Web target by analogy.
