# 質問JSON仕様

質問定義はJSONだけで管理し、scripts/build_form.py でHTMLへ埋め込む。HTMLやJavaScriptを質問ごとに書き換えない。

## フォーム共通項目

| キー                          | 必須 | 内容                                                     |
| ----------------------------- | ---- | -------------------------------------------------------- |
| schemaVersion                 | 必須 | 数値1                                                    |
| formId                        | 必須 | 英数字開始、英数字・ハイフン・アンダースコアで64文字以内 |
| title                         | 必須 | フォームの表題                                           |
| subtitle、description、notice | 任意 | 小見出し・説明・注記                                     |
| output.heading                | 必須 | Markdownの見出し                                         |
| output.context                | 任意 | Markdownの対象説明                                       |
| output.filename               | 必須 | ディレクトリなしの .md ファイル名                        |
| questions                     | 必須 | 1～500問の配列                                           |

## 質問項目

| キー                              | 必須 | 内容                                                                         |
| --------------------------------- | ---- | ---------------------------------------------------------------------------- |
| id                                | 必須 | 英数字開始、英数字・ハイフン・アンダースコアで64文字以内。同一フォームで一意 |
| number                            | 任意 | 表示番号。省略時は id                                                        |
| group、title                      | 必須 | 分野・質問文                                                                 |
| priority、context、recommendation | 任意 | 優先度・背景・推奨案                                                         |
| choices                           | 任意 | 0～26件。空なら自由記述のみ                                                  |
| choices[].id                      | 必須 | 英数字開始、英数字・ハイフン・アンダースコアで32文字以内。同一質問で一意     |
| choices[].label                   | 必須 | 選択肢の文言                                                                 |
| defaultMultiple                   | 任意 | 真偽値。未設定なら単一選択                                                   |

既存のQA質問から生成するときは質問ID Q-xxx を questions[].id にそのまま設定する。意味の変わった質問へ既存IDを再利用しない。フォームごとに formId を分ける。

## 回答の扱い

- 入力から「未回答」「一部回答」「回答済み」を自動判定する。「保留」はチェックボックスで指定する。
- 選択肢を持つ質問で補足だけなら「一部回答」。自由記述のみへの入力は「回答済み」。
- 「記入した回答をコピー」は入力または保留のある質問だけ、「全問をコピー」「Markdown保存」は未回答も含む全質問。
- 推奨案はMarkdown回答に含めず、自動選択もしない。
- 回答はブラウザの localStorage に一時保存できる場合がある。保存は端末や実行環境に依存する。
- 質問文字列のHTML埋め込みは生成器がエスケープする。JSONをHTMLへ手貼りしない。
- 回答内容は質問IDと照合してから担当Skillへ返し、QAの仕様根拠や承認済み仮定へ直接昇格させない。
