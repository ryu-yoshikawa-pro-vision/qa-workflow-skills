# Eval Input

## 変更

検索ランキングが利用者の閲覧履歴と時間帯で変わる。実利用では入力分布が偏り、稀な組合せも障害原因になる。

## 目的

Random Testingの採用要否、運用プロファイルとリスクに応じたテスト深度を決める。

## 現在有効な仕様根拠

- `SPEC-SRCH-005`（承認済み・current）：検索ランキングは閲覧履歴と時間帯を入力として順位を決める。合否は、運用プロファイルの分布から抽出した入力に対して、上位10件に関連商品が基準割合以上含まれることで判定する（基準割合はプロダクトオーナー承認済み）。
- 運用プロファイルの具体的な分布値と発生率は未取得で、取得経路は別途決める。
