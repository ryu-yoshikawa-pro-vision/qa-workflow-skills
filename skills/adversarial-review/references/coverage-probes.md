# カバレッジレビュー プローブ

このreferenceはカバレッジ分析または残存リスクを反証レビューする場合だけ読みます。

カバレッジ基準 / カバレッジ項目の設計は`test-condition-design`、カバレッジ / ギャップ判定は`coverage-analysis`を正本とします。

## カバレッジ分析

主に次を疑います。

- 現在有効な仕様根拠 / プロダクトリスクからテストケースまでの各層が下流接続または妥当な扱いへ閉じているか
- プロダクトリスクが下流へ接続されず消えていないか
- 件数比較やIDリンクだけを意味上のカバレッジとして扱っていないか
- 入力されたカバレッジ基準に対する充足を実際の証拠で確認しているか
- 下流成果物不存在をブロック中と誤判定せずカバレッジギャップとして扱っているか
- 不十分なテストケースをカバレッジ済みと誤認していないか
- `要再検証`の成果物を最新のカバレッジ証拠として数えていないか
- ギャップや不正な扱いの修正先が最も早い責任Skillになっているか
- カバレッジ分析自身が上流成果物を再設計していないか

## 残存リスク

主に次を疑います。

- 対象内の未カバー内容が明示されているか
- 理由と関連プロダクトリスクが追跡できるか
- 高プロダクトリスクの未カバーが無処置で見逃されていないか
- 重大な未カバーを受容済みとする場合、必要な明示承認 / 承認参照があるか
- `対象外`や`ブロック中`を便宜的に使って残存リスクを隠していないか

重大度や残存リスク受容の処置条件は`adversarial-review`基本ガイダンスを正本とします。
