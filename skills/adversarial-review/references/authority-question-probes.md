# 仕様・不明点レビュー プローブ

このreferenceは、仕様分析 / 現在有効な仕様根拠 / 不明点 / 仮定を反証レビューする場合だけ読みます。

詳細な仕様根拠解決アルゴリズムは`spec-analysis`、未解決事項分類・回答正規化は`question-analysis`を正本とします。

## 仕様分析 / 現在有効な仕様根拠

主に次を疑います。

- 仕様・Decision・Inference・Unknownの分類が混ざっていないか
- 分類とIDが一致しているか
- 正本一覧の同じDecision / 仮定を別IDで重複管理していないか
- 対象スコープの有効な仕様根拠が正規化ビューから欠落していないか
- 古い / 撤回済み / 置換済みの根拠を現在有効として扱っていないか
- 実装や既存テストケースを、根拠なく仕様根拠へ昇格していないか
- 仕様根拠の競合を未解決のまま下流へ流していないか
- 対象範囲外の周辺仕様を無根拠に追加していないか

仕様根拠の優先関係・version・Decision / ASM詳細判断が必要なら、`spec-analysis`の契約に照らし、ここで別アルゴリズムを作りません。

## 不明点 / 仮定

主に次を疑います。

- 本来下流の正しさを成立させない論点を非ブロッカー扱いしていないか
- 逆に、局所論点を必要以上に全体ブロッカーへ広げていないか
- 未承認の仮定が完成済み期待結果 / PASS条件へ混入していないか
- AI自身が仮定を承認済みにしていないか
- 回答済み論点が適切な仕様根拠へ正規化されず、生の会話情報のまま下流へ流れていないか
- 解決済み事項を再質問していないか
- 実装差分だけを理由に不要な仕様質問へ戻していないか

ブロッカー / 要確認 / 仮定可能 / 提案・任意の詳細分類は`question-analysis`を正本とします。
