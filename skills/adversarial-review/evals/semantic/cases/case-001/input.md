# Eval Input
## Authority
- viewerは設定を更新できない。
- 51文字以上の名称は保存不可。
- 保存失敗時は既存名称を維持する。

## Review対象 Test Cases
### TC-001
前提: viewerでログイン。
手順: 設定名を「新名称」に変更し保存。
期待結果: 保存成功し一覧に「新名称」が表示される。

### TC-002
前提: editorでログイン。
手順: 51文字の名称を入力し保存。
期待結果: エラーとなり、一覧では既存名称が維持される。

### TC-003
前提: editorでログイン。
手順: 1文字の名称を入力し保存。
期待結果: 保存成功し一覧に1文字名称が表示される。
備考: 手順文の読点が一つ不足している。

## 目的
Cold Reviewとして実在欠陥、False Positive、重大度、修正先を評価する。
