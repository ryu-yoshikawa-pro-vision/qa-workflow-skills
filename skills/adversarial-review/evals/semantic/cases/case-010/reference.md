# 判定根拠

- R-001の全ユーザー更新可能とR-002のviewer更新不可は矛盾する。どちらを採用するか仕様Authorityの決定が必要であり、レビュー対象だけで正解を創作しない。

- R-003の成功画面条件について、HTTPコードや認可済みの意味は文書だけでは確定できない。コードやTCの新規作成を要求しない。
- `adversarial-review`が静的レビューを行い、lint等の実ツールを起動したと偽らない。正式欠陥Issueは自動登録しない。
