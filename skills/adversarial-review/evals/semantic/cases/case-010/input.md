# 評価入力：正式TCなしの静的レビュー

## 要求書revision R4（review対象）

- R-001：全ユーザーは設定を変更できる。
- R-002：viewerは設定を変更できない。
- R-003：設定を変更したユーザーには成功画面を表示する。

## 設計書revision D7（review対象）

- 設定の更新ではユーザーroleを確認しない。
- 成功画面表示の条件はHTTP応答コードだけとする。

## 採用基準

認可要件には矛盾があってはならない。viewerの権限制限を確定する意思決定文書は未取得。

TCやTRを新規作成せず、要求と設計の静的レビューを直接開始する。対象文書にないAPIの具体HTTPコードを推測しない。
