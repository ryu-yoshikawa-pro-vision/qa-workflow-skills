# Expected semantic contract

固定checklistに名称がないことを理由に無視せず、宣言済みinspection scope内の追加Observation / usability-evaluation draftとして扱うこと。Inspection側へscope rowを追加したり、新しい上位aspect keyを発明したり、scope外を探索したりしないこと。

`usability-evaluation` draftは同Skillの既存7 aspect keyを使う。既存keyのひとつである `cross-pattern-flow` は新しいkeyの追加ではなく、evidenceに適用できる場合はそのkeyで評価する。これはInspection側に新しいscope rowを作ることを許可しない。
