# WAI-ARIA and ARIA in HTML

Official sources: [WAI-ARIA 1.2](https://www.w3.org/TR/wai-aria-1.2/) and [ARIA in HTML](https://www.w3.org/TR/html-aria/).

Use the target markup's normative host-language and ARIA requirements when interpreting semantics, names, roles, values, and states. ARIA does not replace native HTML semantics. This summary does not reproduce specification text; use the versioned normative sources and the applicable semantic procedure contract.
