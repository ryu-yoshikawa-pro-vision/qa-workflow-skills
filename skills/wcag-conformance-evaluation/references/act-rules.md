# ACT Rules

Official sources: [ACT Rules Format 1.1](https://www.w3.org/TR/act-rules-format/) and the [published ACT Rules inventory](https://www.w3.org/WAI/standards-guidelines/act/rules/).

ACT Rules are testing methods. Their outcomes do not by themselves establish a complete Success Criterion result. This package dispatches only the rules explicitly listed in `assets/test-rule-catalog.json`; it does not claim that every published rule is implemented.
