# Guidance on Applying WCAG 2.2 to Mobile Applications

Official source: [WCAG2Mobile](https://www.w3.org/TR/wcag2mobile-22/).

The source is a W3C Group Draft Note published 6 May 2025 and is informative. Use it only when the evaluated Web product includes mobile Web or responsive concerns. It does not extend this Skill to native applications and does not replace WCAG 2.2's normative text.
