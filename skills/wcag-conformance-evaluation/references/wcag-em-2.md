# WCAG Evaluation Methodology (WCAG-EM) 2.0

Official source: [WCAG Evaluation Methodology (WCAG-EM) 2.0](https://www.w3.org/TR/wcag-em-2/). The W3C published it as a Group Note on 23 July 2026. The dated publication is [the 23 July 2026 version](https://www.w3.org/TR/2026/NOTE-wcag-em-2-20260723/).

This Skill follows WCAG-EM 2.0 for product scope, exploration, representative sampling, evaluation, and reporting. The methodology is informative and does not add WCAG requirements. This Skill evaluates Web products and uses the separately versioned WCAG 2.0, 2.1, or 2.2 normative catalog selected for the evaluation.

The canonical implementation details live in `assets/output-template.md`, the versioned assets, and the production helpers. This reference does not replace them with a prose-only procedure. Sampling identities, 10% random target rounding, closure, report requirements, and claim guards follow the repository Plan and deterministic helpers.
