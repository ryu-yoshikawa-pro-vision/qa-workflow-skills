# Understanding Accessibility Support

Official source: [Documenting Accessibility Support for Uses of a Web Technology](https://www.w3.org/WAI/WCAG22/Understanding/accessibility-support.html).

The accessibility-support baseline is specific to the evaluation. Record the browser, assistive technology, adaptive approach, software, settings, language, and evidence that were actually selected. Do not infer that an arbitrary technology or browser/AT combination is accessibility-supported.
