# WCAG-EM Report Tool

Official source: [WCAG-EM Report Tool](https://www.w3.org/WAI/eval/report-tool/), updated 11 August 2026 as version 4.1.0.

The tool supports evaluators in recording findings and now uses WCAG-EM 2 terminology. It is an informative resource, not this package's schema or renderer authority. This Skill uses its canonical Markdown template and production helper; it does not import the tool's JSON or HTML export contract.
