## Given / When / Then構造の実行前YAML

入力snapshotに固定した全TCを実操作前に記録します。secret実値を複製せず、既存参照または実値を含まない表現にします。外部ファイルを任意に保存できますが、このMarkdown内のYAMLを省略しません。実測結果で期待結果を書き換えません。

```yaml
test_case_ref: input-001
source_test_case_id: null
title: 入力TCの名称
scenario:
  given:
    - 元TCで指定された開始状態
  when:
    - step_ref: step-001
      action: 元TCの操作
  then:
    - after_step_ref: step-001
      expected: 元TCの期待結果
      observation:
        - accessibility_tree
unresolved: []
cleanup: []
```
