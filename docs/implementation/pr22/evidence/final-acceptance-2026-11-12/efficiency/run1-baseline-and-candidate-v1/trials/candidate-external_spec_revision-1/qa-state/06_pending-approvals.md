## 承認依頼の要点（承認者向け）

0. **P-CART-15（改版起因・局所の最優先）**: 上限値は50か99か（BR-CART-001 と AC-CART-001 の矛盾）。上限値の具体境界（TCN-001）を確定する前提。
1. **P-CART-07（最優先）**: 拒否された操作で親カート版数が増えるか。これだけは期待結果に直接影響する。
2. P-CART-08 / P-CART-09: 境界ケースの扱いの提案に対する可否。
3. P-CART-01 / P-CART-03 / P-CART-06 / P-CART-05b: 補助文書の規則を承認済み仮定として使うか、正本化するか。
4. P-CART-05: 価格改定承認の単位（カート単位か明細単位か）と、複合問題の解除条件。
5. P-CART-11 / P-CART-12: 表示順と正本化。

## 再開

- 承認された項目は、対応するTCNの「保留」を解除して `test-condition-design` を再開する。
- 正本化された項目は `spec-analysis` から再開し、影響するTCNだけを要再検証とする。
- 承認されない項目は、保留のまま残す（期待結果は作らない）。
