## 矛盾の扱い

- 矛盾として確定したものはない。以下は文言差・意図された差として扱う。
  - 統合時の超過（SPEC-CART-002「除外」、SRC-004「切り捨て通知」）: 超過分を統合しない点で一致。
  - 通常操作の超過（全体拒否）と統合の超過（超過分のみ除外）: 仕様上の意図的な差。両方を別観点で設計する。
