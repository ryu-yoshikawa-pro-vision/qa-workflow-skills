# テスト観点・条件 / カバレッジ項目: カート

## 観点範囲

- 対象テスト要求: TR-001〜TR-014（`04-test-requirements.md`）
- テストレベル: システム（Web デスクトップ、Android）
- 対象外: テストケース設計（`test-case-design` の範囲）、テスト実行、カバレッジ分析（`coverage-analysis`）、独立レビュー
- 仮定 / 未解決事項: ブロッカー（局所）Q-001, Q-002。要確認 Q-003〜Q-013。仮定候補 ASM-P1, ASM-P2 は承認待ちで、期待結果の根拠に使わない

### 表記

- `L` = 数量上限 = min(在庫数, 購入上限数, 99)。具体値は作らない（テストケース設計で決める）
- 期待結果欄の「確定」は正式仕様（SPEC）から導けるもの。「保留（Q-xxx）」は期待結果が未確定のため、その条件を実行可能とみなさない
