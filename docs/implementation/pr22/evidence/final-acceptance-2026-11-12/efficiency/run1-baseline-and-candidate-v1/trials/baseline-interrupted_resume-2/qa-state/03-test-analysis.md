## 5. 選択したテスト技法

| テスト技法                           | 適用領域                                                                                          | 選択理由                                     | 関連プロダクトリスク / 現在有効な仕様根拠        | `test-condition-design`への着眼点                                       |
| ------------------------------------ | ------------------------------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------ | ----------------------------------------------------------------------- |
| 境界値分析（BVA）                    | 数量の上限（L = min(在庫数, 購入上限数, 99)）の前後、0の境界                                      | 上限ちょうど・上限+1 の判定が仕様の中心      | RISK-001, S-01, BR-CART-001                      | L-1 / L / L+1、0、在庫0。追加（合算後）と数量変更（絶対値）を分けて扱う |
| デシジョンテーブル                   | 上限の最小値判定、再検証とチェックアウト開始ゲート、統合の除外理由                                | 複数条件の組合せで結果が変わる               | RISK-001, RISK-003, RISK-004, RISK-005, RISK-006 | 三条件の最小値の組合せ、承認状態×価格変更×問題有無、除外理由の組合せ    |
| 状態遷移                             | チェックアウトゲート（価格変更の有無・承認の状態）、カートの状態（active / consumed / abandoned） | 終端状態と承認前の進行可否が仕様の中心       | RISK-004, RISK-005, S-06, S-11                   | 承認前の進行不可、終端からの変更不可（D-04）                            |
| 同値分割                             | 数量入力の有効範囲と無効範囲、統合の対象 / 非対象                                                 | 有効・無効の区分が明確                       | RISK-001, RISK-006                               | 無効値の区分（PA-02 待ち）                                              |
| CRUD / 権限マトリクス                | カートの操作（追加・変更・削除・表示）× ロール（guest / customer / operator / admin）             | 操作とロールの組合せを機械的に網羅できる     | RISK-007, S-07                                   | 利用可否の組合せ                                                        |
| エラー推測                           | 二重実行、古いカートバージョンからの操作、統合の途中失敗                                          | 仕様に根拠（S-09、Q-04、Q-10）がある場合だけ | RISK-008, RISK-011, RISK-005                     | 根拠が未確定の項目は保留                                                |
| 要件ベースの列挙（表示項目・UI状態） | 明細表示項目、画面状態（default / empty / invalid-items）× 対象者 × プラットフォーム              | 仕様が状態を列挙している                     | RISK-009, S-08, S-10                             | 列挙された状態の網羅。並び順は対象外                                    |

適用しない技法: Metamorphic（明示された入出力の関係がない）、Random（固定seedの運用profileが仕様にない）、Pairwise（UI状態は仕様で列挙済みのため網羅可能）、Syntax-Based（文法なし）。

## 7. 対象外 / 別テストレベル

- 注文作成・決済への変換（checkout-and-payment、BR-CHECKOUT-002）: 対象外。境界として参照のみ
- 商品詳細からのカート追加可否（storefront、BR-STOREFRONT-003）: 対象外。カート側は在庫0の追加拒否（D-01）のみ扱う
- 管理者による在庫・価格の変更の操作そのもの: 対象外（テストデータ準備にのみ使用）
- 注文後（consumed）のカートの履歴表示: 仕様に記載なし。対象外として扱い、Q-09 の再アクセス時挙動に限定する
