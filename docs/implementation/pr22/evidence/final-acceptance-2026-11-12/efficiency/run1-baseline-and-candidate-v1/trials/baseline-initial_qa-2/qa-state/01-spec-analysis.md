# 仕様分析: カート（SPEC / DECISION / INFERENCE / UNKNOWN）

## 分析範囲

- 対象機能: カート（ゲスト・会員のカート操作、在庫・上限・公開状態・価格の再検証、ログイン時のゲストカート統合）
- 対象画面 / ロール: `SCREEN-STOREFRONT-CART`（`/cart`）、ゲスト・顧客（有効）。オペレーター・管理者・停止顧客は利用不可として扱う
- 対象外: 注文データへの変換（Order作成・`consumed`化）、決済、チェックアウト画面の詳細（チェックアウト機能側で定義）
- 制約: 製品コードは期待挙動の根拠にしない（補助のみ）。テストケースや期待値の具体数値は作らない
