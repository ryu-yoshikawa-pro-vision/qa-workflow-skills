## 6. 処理 / 業務フロー

1. ゲスト・customer が商品詳細から追加 → active カート取得または作成 → 明細加算 → 版数+1（SPEC-002, SPEC-009, SPEC-010）
2. カート画面表示 → 再検証 → 問題・価格変更を表示（SPEC-006, SPEC-007, SPEC-012）
3. 承認または修正 → チェックアウト開始（SPEC-007, SPEC-008）
4. ログイン → customer のみゲストカート統合（SPEC-003〜005）
