# 01 仕様分析: カート機能

- 対象機能: カート（ゲスト・会員のカート操作、数量変更、明細削除、表示時・チェックアウト開始時の再検証、ログイン時のゲストカート統合）
- 対象 / 実行範囲: 上流前提（テスト分析の入力）
- 対象製品: `product/`（commit 2a8bcf57）
- 対象画面 / ロール: SCREEN-STOREFRONT-CART（`/cart`）、ゲスト・customer（operator / admin は利用不可）
- 対象外: 注文変換（`consumed`、注文明細化）、決済・再決済、チェックアウト画面の振る舞い、注文確認・注文作成時の再検証（いずれも`cart.md`目的、`state-and-scenarios.md`で注文・チェックアウト側に定義）
- 制約: 実装コード・既存テスト・稼働UIは仕様根拠にしない（`spec/README.md`）
