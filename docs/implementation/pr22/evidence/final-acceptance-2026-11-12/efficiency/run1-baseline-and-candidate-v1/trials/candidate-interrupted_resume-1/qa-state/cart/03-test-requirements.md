# テスト要求: カート（cart）

## 要求範囲

- 対象機能: カート機能（`product/docs/spec/features/cart.md`、commit 2a8bcf57）。変更差分は未提示のため機能全体を対象とする（`01-test-analysis.md`と同じ扱い）。
- テストレベル: システムテスト（既定。案件コンテキスト・ユーザー指定に別レベルなし）。観測方法は「UI観測＋カート状態の観測手段（要確認）」。
- 対象外:
  - 注文データへの変換（cart.md 目的。checkout-and-payment / orders で扱う）
  - 商品の追加可否（BR-STOREFRONT-003。storefront で扱う。カート側は追加後の再検証で扱う）
  - ログイン・セッション処理そのもの（authentication で扱う。統合結果だけを検証する）
  - SCREEN-STOREFRONT-CART の android 版の `empty` / `invalid-items`（仕様の必須プラットフォームが web-desktop のみのため）
- 仮定 / 未解決事項: `02-question-analysis.md` の Q-01〜Q-12 を参照。保留項目に依存する要求は「期待結果の確定」を保留するが、要求の存在自体は保留しない（責務は仕様上明確なため）。
- 仮定（本ファイルの前提）: 画面ロール `customer` は cart.md の「会員」と同一とみなす。

## Machine Runtime / Entity（機械証拠）

本要求の作成では `requirement_structure` のdeterministic runtime dispatchと最終 `verify_runtime_evidence` gate を実行していない（`01-test-analysis.md` と同じ理由: runtime入力の正規化形式を確認しきれず、機械証拠（runtime-v2 / entity-state-v2）を手組みしないため）。そのため本ファイルは機械検証済みの完成物ではなく、人間向けの要求定義として扱う。runtime Entityは未作成。
