# 04 テスト要求: カート（test-requirement-design 相当）

- 入力: `01-spec-analysis.md`、`02-question-analysis.md`、`03-test-analysis.md`
- 対象 / 実行範囲: カート（SCREEN-STOREFRONT-CART、BR-CART-001〜003、AC-CART-001〜003）
- テストレベル: システム（03 §6）
- 状態の凡例: **確定** = 現在有効なSPEC / DERIVEDだけで要求を定義できる。**一部ブロック中** = 要求の一部がPAの承認待ち。**ブロック中** = 要求全体が承認待ち（期待が定義できない）

## 1. 要求範囲

- 対象機能: カートの追加・数量変更・削除、表示時 / チェックアウト開始時の再検証、ゲストカート統合、画面状態、利用権限
- 対象外: 注文作成・決済、商品詳細からの追加可否、管理者操作（03 §7）
- 仮定 / 未解決事項: 02 の Q-01〜Q-16、新規候補 Q-17（他ユーザーのカート遮断の規定がない）。ASM-CART-CAND-01（統合時の許容上限）は未承認のため、期待値に使わない
