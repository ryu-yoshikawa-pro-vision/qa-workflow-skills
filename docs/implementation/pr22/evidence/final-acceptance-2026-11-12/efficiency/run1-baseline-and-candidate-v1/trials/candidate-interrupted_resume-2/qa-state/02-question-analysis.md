# 02. 不明点・矛盾の分類（question-analysis）— カート機能

- 入力: `01-spec-analysis.md` の UNK / INF / C-01〜C-11
- 作成日: 2026-11-13
- 承認待ちの正式な記録は `pending-approvals.md` を正本とする。本ファイルは分類のみ。

## 分類の定義

- **ブロッカー**: 当該範囲のテスト設計が意味を持たない（全体停止の対象）
- **局所ブロック（保留）**: 特定の条件・期待結果だけを止める。他の範囲は継続
- **仮定可能（承認待ち）**: 仮定を置けるが、正式仕様への昇格には承認が必要。承認なしに期待結果の根拠として使わない
- **提案**: 仕様の改善提案。テスト設計の進行に影響しない
- **任意**: 記録のみ
