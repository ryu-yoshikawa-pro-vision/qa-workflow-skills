## 4. 上限・境界の決定規則（TCN-001〜007）

- 上限 U = min(在庫数 S, 購入上限数 L, 99)。`cart.md` BR-CART-001 の記述どおり。
- 境界の組（各上限について U と U+1）:
  - 受理: 指定数量 = U → 数量を変えて反映する
  - 拒否: 指定数量 = U+1 → 全体を拒否し、直前の数量を維持する
- 3つの候補のどれが最小かで3クラスに分けます（S が最小 / L が最小 / 99 が最小）。同値のタイ（S = L）も1クラスとして扱います。
- 「許容上限」（PA-01）は統合時の上限です。TCN-010 だけで使い、TCN-001〜007 では使いません。
