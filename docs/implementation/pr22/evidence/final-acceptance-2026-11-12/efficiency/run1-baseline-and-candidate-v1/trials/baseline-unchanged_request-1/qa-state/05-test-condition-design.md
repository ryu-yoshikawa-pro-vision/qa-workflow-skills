### TCN-005（2-wise 組合せ）

因子（1 = 問題あり）: P 公開停止、A 購入権限なし、C 価格変更あり、S 在庫切れ。全16組合せのうち、全2-wise（4因子×2値の組、計24組）を覆う最小の5件（L-OA: 0000, 0011, 0101, 1001, 1110）を検算しました。制約はなし（4次元は独立の判定と cart.md BR-CART-003 で規定）。単独不備は2-wiseに含まれないため別途追加。

| カバレッジ項目ID | 組合せ（P, A, C, S） | 備考                         |

| TCN-005-CI01     | 0, 0, 0, 0           | 問題なし                     |
| TCN-005-CI02     | 0, 0, 1, 1           | 価格変更＋在庫切れ           |
| TCN-005-CI03     | 0, 1, 0, 1           | 権限なし＋在庫切れ           |
| TCN-005-CI04     | 1, 0, 0, 1           | 公開停止＋在庫切れ           |
