## 2. 変更の位置づけ（仕様との関係）

製品の正本（`product/docs/spec/features/cart.md`）は数量上限を明示的に99と定めている。

- `BR-CART-001`: 「カート内の数量は『在庫数』『購入上限数』『99』のうち最小値を超えない」
- `AC-CART-001`: 「在庫数、購入上限数、99の各境界値において、…現在の数量が維持されること」

同じ99は次にも記載されている（いずれも今回の変更では更新されていない）。

- `product/docs/04_data/application_contracts.md` 101行目: `maxCartQuantity: 99`（UI・Zod・ユースケースが`INPUT_LIMITS`を共通利用すると定義）
- `product/docs/05_ui/validation_and_messages.md` 42・44行目: 購入上限・数量「1〜99の整数」
- `product/docs/03_domain/business_rules.md` 137行目: 上限値99
- `product/docs/future/phase2/sqlite_schema.md`（BETWEEN 1 AND 99、将来設計）

したがって、今回の変更は**製品コードが正本仕様から逸脱した状態**を作る。仕様変更として正式に承認された記録はなく、どちらが意図かは本作業では判断できない（判断者は未特定）。

## 4. 検出された逸脱（新規の保留事項）
