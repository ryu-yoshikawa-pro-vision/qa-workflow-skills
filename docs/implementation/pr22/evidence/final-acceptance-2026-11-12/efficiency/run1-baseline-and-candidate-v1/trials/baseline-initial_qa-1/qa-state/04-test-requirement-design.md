# 04 テスト要求: カート機能

## 要求範囲

- 対象機能: カート（`product/docs/spec/features/cart.md`）
- テストレベル: システムテスト（Web: web-desktop、ネイティブ: Android）
- 対象外: 注文変換（consumed、注文明細化）、決済・再決済、注文確認・注文作成時の再検証（注文・チェックアウト側の要求）
- 仮定 / 未解決事項: `02-question-analysis.md`のQ-001〜Q-010。仮定候補は未承認のため要求の根拠に使用しない
