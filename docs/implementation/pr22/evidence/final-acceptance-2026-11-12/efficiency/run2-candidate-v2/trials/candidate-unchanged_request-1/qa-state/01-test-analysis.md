## 補足: 仕様の整合上の注意（テスト分析の入力として記録）

- `cart.md` の `empty` 状態は `BR-CART-001` に関連付けられているが、空状態は数量上限の内容と直接対応しない。トレーサビリティの確認が必要（Q-06）。
- `cart.md` の AC-CART-002 は「カートバージョン」に言及するが、同ファイルのBRにはカートバージョンの定義がない。状態・バージョンの定義は `03_domain/state_transitions.md` にあるが、これは正式仕様（features/**）ではない（Q-02）。
- 数量の入力範囲は `validation_and_messages.md` で「1〜99、上限以下」、`cart.md` BR-CART-001 では「0で削除」。UIでの0入力の扱いが両文書で一致していない（Q-03）。
