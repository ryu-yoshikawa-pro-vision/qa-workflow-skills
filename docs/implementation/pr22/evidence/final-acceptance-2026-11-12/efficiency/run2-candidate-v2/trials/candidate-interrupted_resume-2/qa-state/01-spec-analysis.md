# 仕様分析: カート（`spec-analysis`）

## 分析範囲

- 対象機能: カート（商品追加、数量変更、削除、表示時の再検証、チェックアウト開始前の再検証、ログイン時のゲストカート統合）
- 対象画面 / ロール: `SCREEN-STOREFRONT-CART`（`/cart`）、ゲスト・一般顧客（customer）。運用者・管理者・停止中顧客の扱いは権限節で扱う
- 対象情報源: 下表SRC-001〜SRC-007
- 対象とする正本一覧: `product/docs/spec/README.md`の「正式な製品動作」（`product-scope.md`、`roles-and-permissions.md`、`state-and-scenarios.md`、`ui-ux-contract.md`、`features/**/*.md`）
- 対象外: 注文作成・注文確認時の再検証（`checkout-and-payment.md`が定義）、在庫減算（注文時）、商品管理
- 制約: 製品commit `2a8bcf57`はユーザー申告で、ワークスペース内では照合できていない
