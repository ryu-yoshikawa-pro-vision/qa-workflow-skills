# カート テスト観点・条件 / カバレッジ項目（test-condition-design 草案）

- 入力: `04-test-requirements.md`（有効TR 15件）、`03-test-analysis.md`（技法選択）、`01-spec-authority.md`
- 期待結果は SPEC のみから書く。UNKNOWN に依存する期待結果は「保留（P-xx）」と記す
- 機械証拠: なし（手作業草案）。カバレッジ項目の網羅率は未計測

記号: L = min(在庫数, 購入上限数, 99)。L は SKU ごとに決まる。
