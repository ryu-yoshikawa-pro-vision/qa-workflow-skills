# テスト観点・条件 / カバレッジ項目: カート（`test-condition-design`）

## 観点範囲

- 対象テスト要求: TR-CART-001〜015（`04-test-requirements.md`）。保留TR-CART-P01〜P05は観点を作らない（Q-001）
- テストレベル: システムテスト（UI）。別テストレベルの項目はTCN内で明示
- 対象外: 注文作成・注文確認の再検証、在庫減算（注文時）
- 仮定 / 未解決事項: Q-001〜Q-007（`02-question-analysis.md`）。仮定ASMは期待結果に使わない

## 期待結果の根拠の扱い

- 期待結果は`SPEC-xxx`（`features/cart.md`、`state-and-scenarios.md`、`roles-and-permissions.md`、`storefront.md`）と`DEC-001`の範囲だけに限定する
- 補助文書の値（版、相対/絶対数量、表示順、統合失敗、在庫非減算）は使わない
- 期待結果が空欄の観点は保留であり、推測で埋めない
