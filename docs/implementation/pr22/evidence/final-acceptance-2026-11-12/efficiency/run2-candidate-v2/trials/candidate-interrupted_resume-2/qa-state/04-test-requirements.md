# テスト要求: カート（`test-requirement-design`）

## 要求範囲

- 対象機能: カート（`product/docs/spec/features/cart.md`、`SCREEN-STOREFRONT-CART`）
- テストレベル: システムテスト（既定）。版・統合の内部状態は別テストレベルで扱う（`03-test-analysis.md`）
- 対象外: 注文作成・注文確認時の再検証（checkout機能）、在庫減算（注文時）、商品管理
- 仮定 / 未解決事項: `02-question-analysis.md`のQ-001〜Q-007。仮定ASMは未承認のため使用しない

## 凡例

- 状態「有効」: 現在有効な仕様根拠（SPEC・DECISION）だけで検証責務を確定できる
- 状態「局所保留」: 一部の次元だけが未決（ブロッカーQ-xxx）。有効な次元だけ継続
- 状態「保留」: Q-001の承認待ち（補助文書の契約）。期待結果を確定しない
