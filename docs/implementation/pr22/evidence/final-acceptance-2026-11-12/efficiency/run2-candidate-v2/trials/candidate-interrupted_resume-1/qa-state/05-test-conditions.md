# 05 テスト観点・条件 / カバレッジ項目: カート（`features/cart.md`）

- 対象 / 実行範囲: テスト観点・条件設計（TR-001〜TR-016）

## 6. 技法の充足状況

- 境界値分析（TCN-001）: L-1 / L / L+1 と、Lを決める3上限の確認まで定義済み（実値はP-05）
- 決定表（TCN-005 / TCN-007 / TCN-008）: 条件とルールを定義。ブロック中のルールは明示
- 状態遷移（TCN-006 / TCN-009 / TCN-014）: 有効な遷移と拒否の期待結果を定義。未確定の遷移はブロック中として残す
- 同値分割（TCN-002 / TCN-003 / TCN-010 / TCN-012 / TCN-013 / TCN-015）: 同値クラスを定義
