# 02 質問分析: カート（Q-CART-*）

- 対象 / 実行範囲: question-analysis（01の仕様分析の未解決事項を分類）
- 入力revision: `qa-state/input-revisions.json`（cart.md sha256 `385777e5…7216`）。01の入力revisionと同一。
- 承認状態: **すべて未承認**。回答・承認の記録はこのファイルに無い。承認済みの仮定は存在しない。
- 停止条件の扱い: 下記のブロッカーは該当する期待結果の確定を止める。それ以外の項目は、該当条件だけを保留にして他の条件設計は続行する。

## 分類の凡例

| 分類       | 意味                                                      | 下流への扱い                                               |
| ---------- | --------------------------------------------------------- | ---------------------------------------------------------- |
| ブロッカー | 期待結果を一意に決められない                              | 該当するテスト条件・期待結果を「保留」。回答まで確定しない |
| 要確認     | 解釈が割れる、または正本に記述が無い                      | 該当条件のみ「保留」。他は続行                             |
| 提案       | 正本に無いが、仕様化するとよい項目（INFERENCE由来を含む） | 期待結果の根拠にしない。条件は「提案・未承認」として分離   |
| 任意       | 影響が小さい / 対象範囲外に近い                           | 条件は作らない。記録のみ                                   |
