## 5. カバレッジ項目一覧

### 5.1 上限の境界（TCN-001、TCN-002）

上限の源泉は在庫数（S）、購入上限数（L）、99の3つ。上限 = min(S, L, 99)。各源泉が有効になる分類ごとに、上限−1・上限・上限+1の3値を取る。

前提（テストデータ要件。手順は含まない）: 源泉ごとに、他の2つより小さくなる組合せを成立させる。99が有効な項目は、在庫数と購入上限数の両方が100以上。

| カバレッジ項目ID | 観点ID  | 有効な源泉                  | 境界の値（合算、TCN-001） | 期待挙動の根拠                            |
| ---------------- | ------- | --------------------------- | ------------------------- | ----------------------------------------- |
| CI-001-01        | TCN-001 | 在庫数（S < L、S < 99）     | S−1                       | 受け入れ（SPEC-CART-001）                 |
| CI-001-02        | TCN-001 | 在庫数                      | S                         | 受け入れ                                  |
| CI-001-03        | TCN-001 | 在庫数                      | S+1                       | 拒否・変更前の数量を保持（SPEC-CART-002） |
| CI-001-04        | TCN-001 | 購入上限数（L < S、L < 99） | L−1                       | 受け入れ                                  |
| CI-001-05        | TCN-001 | 購入上限数                  | L                         | 受け入れ                                  |
| CI-001-06        | TCN-001 | 購入上限数                  | L+1                       | 拒否                                      |
| CI-001-07        | TCN-001 | 99（S > 99、L > 99）        | 98                        | 受け入れ                                  |
| CI-001-08        | TCN-001 | 99                          | 99                        | 受け入れ                                  |
| CI-001-09        | TCN-001 | 99                          | 100                       | 拒否                                      |
| CI-001-10        | TCN-001 | 全源泉（拒否時）            | 拒否の操作後              | 数量が変更前の値n（AC-CART-001）          |

| カバレッジ項目ID | 観点ID  | 有効な源泉       | 境界の値（変更後の絶対値、TCN-002） | 期待挙動の根拠                                |
| ---------------- | ------- | ---------------- | ----------------------------------- | --------------------------------------------- |
| CI-002-01〜03    | TCN-002 | 在庫数           | S−1、S、S+1                         | 受け入れ、受け入れ、拒否（TCN-001と同じ判定） |
