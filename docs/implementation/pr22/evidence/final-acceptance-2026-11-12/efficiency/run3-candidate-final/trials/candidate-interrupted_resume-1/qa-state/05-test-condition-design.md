# 05 テスト観点・条件 / カバレッジ項目（test-condition-design）: カート

入力: `04-test-requirement-design.md`（TR-001〜TR-030）、`03-test-analysis.md`、`02-question-analysis.md`（Q-01〜Q-13）。
対象 / 実行範囲: テスト観点・条件設計（カバレッジ基準・カバレッジ項目）。テストケース（手順・期待結果の具体化）は含まない。

## 観点範囲

- 対象テスト要求: TR-001〜TR-030 のうち、ブロック中を除く下記 TR。
- テストレベル: システムテスト。観測は画面（web-desktop / android）。
- 対象外: `04` の「テスト要求を作らない上流項目」と同じ。
- 仮定 / 未解決事項: `02` の Q-01〜Q-13。仮定は置いていない。期待結果は現在有効な SPEC（cart.md）だけから取る。
- 候補母集団: `test-item-analysis` / `test-condition-analysis` の候補は今回作成していない。item × 共通 condition の正式適用は **未適用**（候補母集団が無いため、カバレッジは 100% と扱わない）。
