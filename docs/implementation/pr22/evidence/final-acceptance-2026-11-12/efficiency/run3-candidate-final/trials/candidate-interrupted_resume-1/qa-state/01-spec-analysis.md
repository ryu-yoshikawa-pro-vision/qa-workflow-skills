# 01 仕様分析（spec-analysis）: カート

対象製品: `product/`（commit `2a8bcf57`、ユーザー指定。workspace内は git 管理外のため commit との照合は未実施。入力の同一性は `workflow-state.md` の sha256 で管理）

## 分析範囲

- 対象機能: カート（`product/docs/spec/features/cart.md`）
- 対象画面 / ロール: `SCREEN-STOREFRONT-CART`（`/cart`）、ゲスト、有効な顧客（customer）。運用者・管理者はカート利用不可（ロール表）。
- 対象情報源: 正式仕様（`features/**`、`product-scope.md`、`roles-and-permissions.md`、`state-and-scenarios.md`）と、正本一覧外の関連文書（`03_domain/business_rules.md` §3、`12_quality/acceptance_criteria.md`）。後者は権威判定を保留（UNK-001）。
- 対象とする正本一覧: `spec/README.md` の「正式な製品動作」に列挙された文書のみを SPEC の根拠とする。
- 対象外:
  - チェックアウト・注文への変換（`checkout-and-payment.md`、`orders.md`。cart.md の目的記述で別機能と明記）
  - 商品詳細からの追加ボタンの活性可否（`storefront.md` BR-STOREFRONT-003）
  - ログイン処理そのもの（`authentication.md`。ただし「ゲストカート統合」の仕様本体は cart.md BR-CART-002 が所有）
- 制約: 製品コード・仕様書は変更しない。UI 画面の実観測は行わない（UI 観測は test-target-inspection の責務）。
