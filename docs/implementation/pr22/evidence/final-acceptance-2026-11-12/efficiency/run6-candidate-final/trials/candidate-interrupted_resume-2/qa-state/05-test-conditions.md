# 05 テスト観点・条件 / カバレッジ項目（test-condition-design）— カート機能

## 観点範囲

- 対象テスト要求: TR-001〜TR-018（`04-test-requirements.md`）
- テストレベル: システム（TRの指定どおり）
- 対象外: 注文・チェックアウト側の検証（他機能）、Androidの `empty` / `invalid-items`（SRC-01の表どおり対象外）、表示順・通知文言（仕様根拠なし）
- 仮定 / 未解決事項: 保留は `02-questions.md` の PEND-01〜09 に対応。保留の条件は**期待値を置かない**。`active`（有効）は仕様根拠（SPEC / AC / BR）だけで期待値を決められるもの。REF-01 と未承認INFERENCEは期待値の根拠に使わない。

### 状態の意味

- **有効**: 仕様根拠から期待結果を決められる
- **保留**: 承認・製品判断待ち（PEND-xx）。期待値を置かない。承認後に有効化
- **一部**: 有効な部分と保留の部分が混在（括弧内に保留部分を示す）
