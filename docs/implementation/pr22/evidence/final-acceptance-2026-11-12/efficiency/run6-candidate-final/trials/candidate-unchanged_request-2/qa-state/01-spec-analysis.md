# 01 仕様分析: カート機能（Spec Authority解決）

- 対象製品: `product/`（commit 2a8bcf57 として依頼された対象）
- 対象機能: カート（`product/docs/spec/features/cart.md`）
- 対象画面 / ロール: `SCREEN-STOREFRONT-CART`（Guest / Customer）。Customer は有効（active）な顧客に限る
- 対象とする正本一覧: `product/docs/spec/README.md`「正式な製品動作」= `product-scope.md`, `roles-and-permissions.md`, `state-and-scenarios.md`, `ui-ux-contract.md`, `features/**/*.md`
- 対象外: 注文データへの変換（チェックアウト・注文機能側で定義）、ネイティブ実機のiOS挙動（product-scopeの「ビルド限定契約」）、見た目のピクセル一致（`unresolved-specifications.md` で未確定）

## 8. 後続Skillへの補足

- test-analysis: 上記 SPEC を入力にリスク評価する。UNK は期待結果に使わず、リスクの残存要因として扱う。
- test-requirement-design: TR は SPEC-001〜015 へ追跡する。UNK-001〜011 に依存する TR は「保留・ブロック中」として明示する。
- ui-target-analysis: 本件では package 作成を要求されていないため、`ui-target-v1` package は作成しない（UI構造の分析は画面カタログ・SRC-001 の範囲で足りる）。
