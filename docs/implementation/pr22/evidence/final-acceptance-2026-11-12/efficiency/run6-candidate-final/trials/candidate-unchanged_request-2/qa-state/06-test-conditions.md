# テスト条件・カバレッジ項目: カート機能

- 条件ID（CND-CART-###）は、テストケースの前段階の条件（何を変えて何を確認するか）。期待結果の具体値は、保留の解消後に test-case-design で確定する。
- 「状態: 確定」は仕様根拠に閉じている。「保留」は`pending-approvals.md`の回答待ち。保留条件の期待結果は決めない。

## カバレッジ項目（要約）

- 確定の条件: 上限・統合（判定表）・権限（判定表）・価格ゲート・単価計算・画面の主要状態。
- 保留の条件: 在庫減少時の数量扱い、停止・退会customer、統合の詳細、合計表示、競合・loading、android差分、入力不正・上限0・二重実行（仮定承認待ち）。保留の条件は、回答が出るまで期待結果を決めない。
- 次工程（test-case-design）は、確定の条件から着手できる。保留の条件は回答後に追加する。
