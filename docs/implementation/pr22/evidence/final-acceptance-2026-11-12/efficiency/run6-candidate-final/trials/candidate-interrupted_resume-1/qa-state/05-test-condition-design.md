# テスト観点・条件 / カバレッジ項目: カート（SCREEN-STOREFRONT-CART）

## 観点範囲

- 対象テスト要求: TR-001〜TR-019（`04-test-requirements.md`）
- テストレベル: システムテスト（UI）＋データ状態観測（Cart状態、統合後の明細）
- 対象外: 注文変換、注文側の再検証、`consumed`、ネイティブ詳細、実装コード
- 仮定 / 未解決事項: Q-001〜Q-013。承認されていない仮定 A-01, A-02 は期待結果の根拠にしない。

### 凡例

- 期待結果の状態: **確定**（SPEC根拠が期待結果を定める） / **保留**（未確定のQが期待結果を止める。条件は保持） / **観測限定**（存在・操作可能性のみ、値は仕様未規定）
- 優先度: 高 / 中 / 低
