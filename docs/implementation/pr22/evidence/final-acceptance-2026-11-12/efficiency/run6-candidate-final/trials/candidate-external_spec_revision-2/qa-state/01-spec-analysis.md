## 仕様内の齟齬・曖昧さ（要約）

- 機能の「商品追加」は cart.md の範囲に無く、商品詳細側の仕様（SPEC-CART-14）に依存する。cart.mdだけでは追加操作の検証範囲を決められない。
- 受入基準 §10 は loading / error / conflict / not found を要求するが、cart.md の主要UI状態は default / empty / invalid-items のみ。
- default 状態のみ android を必須プラットフォームにしている。empty・invalid-items が web-desktop のみである理由は書かれていない（Q-CART-10）。
- 合計金額は cart.md に計算式が無く、受入基準 §4 の単価割引ルールに依存する（UNK-CART-06）。
- 【改版】BR-CART-001 の上限値は 99 → 50 に改版された。同じ cart.md 内の AC-CART-001 は「99の各境界値」のままで、BR と齟齬する（UNK-CART-12 / Q-CART-12）。business_rules.md も 99 のまま（Q-CART-13）。改版後の BR を現行仕様として扱い、齟齬は承認待ちとする。
