# 04 テスト要求（test-requirement-design）— カート機能

## 要求範囲

- 対象機能: カート（ゲスト / 会員）。`product/docs/spec/features/cart.md` の BR-CART-001〜003、AC-CART-001〜003、および `03-test-analysis.md` のプロダクトリスク RISK-001〜007
- テストレベル: システムテスト（`03-test-analysis.md` で既定を適用。明示指定なし）
- 対象外: 注文変換・チェックアウト（他機能）、追加ボタンUI（storefront）、Androidの `empty` / `invalid-items`（SRC-01の必須プラットフォーム表に含まれない）
- 仮定 / 未解決事項: 承認が必要な事項は `02-questions.md` の PEND-01〜09 で保留。本ファイルのTRは「何を検証するか」だけを定め、保留の期待値は含めない。TRの根拠 SPEC-CART-xxx は `01-spec-authority.md` を参照

## 追跡性の確認

- 有効な仕様根拠（SPEC-CART-001〜019）のうち、TRへ閉じたもの: 001, 002, 003, 004, 005, 006, 007, 008, 009, 010, 011, 012, 013, 014, 015, 016, 017, 018, 019 — すべて TR または上表の扱いに閉じている
- SPEC-CART-020（AC-CART-001〜003）: TR-001 / TR-004〜009 に分解
- SPEC-CART-021: 上表で別機能として扱い
- RISK-001〜007 の対応: RISK-001 → TR-001〜003 / RISK-002 → TR-004〜006, 012 / RISK-003 → TR-007, 009 / RISK-004 → TR-006, 008 / RISK-005 → TR-010〜012 / RISK-006 → TR-013 / RISK-007 → TR-014〜018
- 未閉鎖の上流項目: なし（すべて「ブロック中」または「対象外」として明示）
