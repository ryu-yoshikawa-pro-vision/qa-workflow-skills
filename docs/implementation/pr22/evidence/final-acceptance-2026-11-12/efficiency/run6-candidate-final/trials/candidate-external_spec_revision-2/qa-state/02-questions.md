## 改版起因の観測（質問ではない）

- 改版後の上限50に対し、実装（`CART_QUANTITY_LIMIT = 99`、`maxCartQuantity: 99`）は99を返す（IMPL-01）。仕様の期待値は50で設計する。TC実行時に、51〜99の数量が受理されれば欠陥候補として扱う（`defect-management`へ）。製品コード・仕様書は本QAで変更しない。

## 仕様内の確認済み事項（質問にしない）

- 操作拒否の挙動（上限超過で数量を補正しない）は cart.md と受入基準で一致している（SPEC-CART-03）。
- operator / admin のカート利用拒否は受入基準 §2 で明示されており、実装とも一致する（SPEC-CART-10）。
- 数量0の削除は cart.md と実装で一致する（SPEC-CART-04）。
