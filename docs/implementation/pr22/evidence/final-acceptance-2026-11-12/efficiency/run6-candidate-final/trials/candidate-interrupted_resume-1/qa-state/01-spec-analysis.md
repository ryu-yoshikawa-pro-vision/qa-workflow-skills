# 仕様分析: カート（SCREEN-STOREFRONT-CART）

## 分析範囲

- 対象機能: カート（ゲスト・会員のカート追加、数量変更、削除、表示時・チェックアウト開始時の再検証、ログイン時のゲストカート統合）
- 対象画面 / ロール: SCREEN-STOREFRONT-CART（`default` / `empty` / `invalid-items`）。ゲスト、顧客（active）。運用者・管理者・停止顧客はカート対象外として確認のみ。
- 対象情報源: `product/docs/spec/` 配下の正式仕様（下記SRC-001〜007）。補助文書は分類を明記して参照。
- 対象とする正本一覧: `product/docs/spec/README.md` の「正式な製品動作」（`product-scope.md`、`roles-and-permissions.md`、`state-and-scenarios.md`、`ui-ux-contract.md`、`features/**/*.md`）。
- 対象外: 注文データへの変換（チェックアウト・注文機能側）、注文確認・注文作成時の再検証（チェックアウト機能側の境界として参照のみ）、ゲスト購入（Phase 2）、ネイティブ実装の詳細（`native-customer.md` のカート節は未精査）、実装コード（`product/src/`）。
- 制約: 製品コードと仕様書は変更しない。`product/` に `.git` がなく、利用者申告の製品commit `2a8bcf57` とは照合していない。
